# Working Area Analysis: Landscape ISO A-Series vs SI 727 Custom Sizes

**Date:** December 23, 2025  
**Analysis:** Comparison of working areas after migration to landscape ISO A-series

## Paper Size Comparison

### Old (SI 727 Custom) vs New (ISO A-series Landscape)

| Category | Old Size | New Size | Paper Area Change |
|----------|----------|----------|-------------------|
| **Small → A2** | 500×400mm | 594×420mm | +24,480 mm² (+12.2%) |
| **Medium → A1** | 800×500mm | 841×594mm | +99,554 mm² (+24.9%) |
| **Large → A0** | 1000×800mm | 1189×841mm | +199,949 mm² (+25.0%) |

## Working Area Calculation

**SI 727 Margins (Unchanged):**
- Left: 50mm
- Right: 150mm
- Top: 50mm
- Bottom: 50mm

**Working Area Formula:**
```
Working Width = Paper Width - Left Margin - Right Margin
Working Width = Paper Width - 50mm - 150mm = Paper Width - 200mm

Working Height = Paper Height - Top Margin - Bottom Margin
Working Height = Paper Height - 50mm - 50mm = Paper Height - 100mm
```

## Key Insights

### 1. Significant Working Area Gains
- **A2 shows the largest percentage increase** at 40.1% - excellent for small subdivisions
- **A1 and A0 show consistent ~31% increases** - substantial improvement for larger projects
- All sizes provide significantly more space for map content and overlays

### 2. Dimensional Characteristics

**A2 (594×420mm):**
- Nearly square working area (394×320mm)
- Excellent for compact subdivisions
- 94mm extra width allows better horizontal layout

**A1 (841×594mm):**
- Balanced landscape format
- 94mm extra height improves vertical space
- Ideal for most cadastral surveys

**A0 (1189×841mm):**
- Large landscape format
- 189mm extra width for extensive surveys
- Perfect for complex multi-parcel projects

### 3. Layout Benefits

**Horizontal Gains (Width):**
- A2: +94mm (31.3%) - More room for left-side data tables
- A1: +41mm (6.8%) - Modest width increase
- A0: +189mm (23.6%) - Substantial width for complex layouts

**Vertical Gains (Height):**
- A2: +20mm (6.7%) - Modest height increase
- A1: +94mm (23.5%) - Significant vertical space
- A0: +41mm (5.9%) - Modest height increase

### 4. Practical Implications

**Better Label Spacing:**
- 31-40% more area means less crowding
- Improved readability of stand numbers and beacons
- More space for annotation and detail

**Improved Block Positioning:**
- Title blocks can be larger and more prominent
- Schedule of Areas can accommodate more parcels
- Beacon descriptions have more vertical space
- Outside Figure Data fits more comfortably

**Reduced Collision Risk:**
- More space reduces overlay block collisions
- Better automatic layout optimization
- Less manual repositioning required

**Professional Appearance:**
- Standard ISO sizes look more professional
- Better proportions for cadastral plans
- Improved visual balance

## Recommendations

### For Small Projects (1-5 parcels)
- **Use A2 (594×420mm)**
- 40% more working area than old Small
- Sufficient for most urban subdivisions
- Cost-effective standard paper size

### For Medium Projects (6-15 parcels)
- **Use A1 (841×594mm)**
- 32% more working area than old Medium
- Ideal for typical cadastral surveys
- Balanced dimensions for most layouts

### For Large Projects (16+ parcels)
- **Use A0 (1189×841mm)**
- 31% more working area than old Large
- Handles complex multi-parcel surveys
- Extensive width for detailed plans

The migration to landscape ISO A-series sizes provides:

- ✅ **Standard paper sizes** for universal compatibility
- ✅ **Professional appearance** with optimal proportions

The landscape orientation is the optimal choice for cadastral survey plans, providing maximum usable area while maintaining professional standards.
